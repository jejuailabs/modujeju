# 관광 데이터 제공기관 접근 조건 확인

확인일: **2026-11-08 (KST)**. 한국관광콘텐츠랩·공공데이터포털의 공개 화면을 컴퓨터 유즈로 읽었다. VisitJeju 항목은 같은 작업에서 별도로 확인한 공식 공개 화면의 결과를 합쳤다. 로그인, 회원가입, 약관 동의, 활용신청, 키 발급, 실제 관광정보 API 호출은 수행하지 않았다. 이 파일에 실제 인증키는 없다.

## 현재 판단

**TourAPI의 아래 세 서비스는 무료 제공이 확인된다. 그러나 정기적으로 응답을 내려받아 로컬 파일이나 데이터베이스에 보관하는 방식의 허용은 확인되지 않았다.** 한국관광콘텐츠랩 정책에 “콘텐츠 캐싱(로컬서버 저장방식) 금지”가 명시되어 있기 때문이다. 저장형 수집기를 TourAPI에 연결하기 전에 이 제한의 적용 범위를 제공기관에 확인해야 한다. API에 동기화 목록 기능이 있다는 사실만으로 저장 허용을 추론하지 않는다. [공식 저작권 정책](https://api.visitkorea.or.kr/#/useServiceGuide/2), [국문 서비스 명세](https://api.visitkorea.or.kr/#/useKoreaGuide)

**VisitJeju는 키 발급 및 트래픽 제한 절차가 확인되지만, 공개 안내에서 무료 여부와 일일 한도 숫자를 확인하지 못했다.** 따라서 비용이 확인되기 전까지 실제 호출이나 주기 실행을 활성화하지 않는다. [VisitJeju 공식 API 안내](https://www.visitjeju.net/kr/visitjejuapi)

## TourAPI: 비용·한도·승인

공공데이터포털의 제공기관 작성 메타데이터를 기준으로 확인했다. 페이지 상단의 AI 요약은 아래 결론의 근거로 사용하지 않았다.

| 서비스 | 무료 여부 | 개발계정 표시 한도 | 운영계정 | 공식 상세 페이지 |
| --- | --- | --- | --- | --- |
| 한국관광공사 국문 관광정보 서비스_GW | 무료 | 1,000 | 심의승인; 활용사례 등록 후 트래픽 증가 신청 가능 | [15101578](https://www.data.go.kr/data/15101578/openapi.do) |
| 한국관광공사 반려동물 동반여행 서비스 | 무료 | 1,000 | 심의승인; 활용사례 등록 후 트래픽 증가 신청 가능 | [15135102](https://www.data.go.kr/data/15135102/openapi.do) |
| 한국관광공사 무장애 여행 정보 | 무료 | 1,000 | 심의승인; 활용사례 등록 후 트래픽 증가 신청 가능 | [15101897](https://www.data.go.kr/data/15101897/openapi.do) |

목록의 `1,000`은 한국관광콘텐츠랩의 활용 안내에서 **하루 트래픽 1,000건**으로 설명된다. 개발계정은 이를 초과하여 이용할 수 없다고 안내한다. 호출 안내에는 자동승인 후 약 10분 이내 사용 가능하다고 적혀 있다. 이는 안내상의 예상이며, 이번 작업에서 발급 시간을 실측한 것은 아니다. [계정 이용 안내](https://api.visitkorea.or.kr/#/useServiceGuide/1), [인증키·호출 안내](https://api.visitkorea.or.kr/#/useOpenapiManual)

확인된 신청 순서는 공공데이터포털 회원가입 → 개발계정 활용신청 → 서비스 키 자동 발급 → 개발·테스트 → 실제 운영을 위한 운영계정 신청이다. 운영계정 심의 항목에는 개발계정 테스트 이력, `MobileApp`의 서비스 고유명, 실제 앱·웹의 관광공사 API 활용 여부가 포함된다. 신청자가 필요한 운영 트래픽을 작성할 수 있으나 승인될 최대 수치와 처리 기간은 공개 안내에서 확인하지 못했다. [공식 신청 절차](https://api.visitkorea.or.kr/#/useServiceGuide/1)

같은 안내에는 서비스 키를 1인당 하나 발급하고 재발급하면 기존 키가 폐기된다고 적혀 있다. **키를 보유했다는 사실과 특정 서비스의 활용승인 상태는 구분해야 한다.** 이 문서에서는 서비스별 신청·승인 확인이 필요하다는 보수적인 운영 기준을 적용한다. [공식 키·계정 안내](https://api.visitkorea.or.kr/#/useServiceGuide/1)

이 확인으로 서버·저장소·스케줄러·호스팅의 무료 이용까지 증명되는 것은 아니다. 데이터 API 이용료와 실행 인프라 비용은 별개이며, 별도 과금이 발생하거나 불확실한 서비스는 사용자의 구체적인 비용 승인을 먼저 받아야 한다.

## TourAPI: 재사용과 출처 표시

세 데이터셋 상세 페이지의 이용허락범위에는 제한 없음이 표시되어 있다. 그러나 한국관광콘텐츠랩의 별도 저작권 정책은 다음 조건을 명시한다. 데이터셋의 짧은 라이선스 표기만으로 개별 사진이나 저장 방식까지 무조건 허용된다고 판단하지 않는다. [국문](https://www.data.go.kr/data/15101578/openapi.do), [반려동물](https://www.data.go.kr/data/15135102/openapi.do), [무장애](https://www.data.go.kr/data/15101897/openapi.do), [저작권 정책](https://api.visitkorea.or.kr/#/useServiceGuide/2)

- API 또는 다운로드한 관광정보를 이용할 때 한국관광콘텐츠랩 또는 한국관광공사의 저작권 출처를 표시한다.
- 사진은 워터마크와 원 제공자에 따라 데이터 제공자·사진 출처 표시가 달라진다.
- 자료의 공공누리 유형을 개별 확인해야 한다. 안내상 제1유형은 출처 표시를 조건으로 상업적 이용과 변경이 가능하고, 제3유형은 출처 표시가 필요하며 변경·2차 저작물 작성이 허용되지 않는다.
- 국문·무장애 API 상세는 제공 사진에 공공누리 제1·3유형이 섞여 있다고 안내한다. 사진을 기업 CI·BI로 쓰거나 피사체의 인격권을 침해하는 용도로 쓰는 것을 금지한다.
- 정책에 로컬 서버 저장 방식의 콘텐츠 캐싱 금지가 적혀 있다. 일시적 응답 메모리, 정규화한 사실 정보, ID 목록, 장기 보관 파일 각각에 적용되는 범위는 이번 공개 안내만으로 확정하지 못했다.
- 외부 사이트에 자료를 직접 연결하거나 업로드할 때 저작권 정책 안내 링크도 제공하도록 안내한다.

위 조건의 근거는 [한국관광콘텐츠랩 저작권 정책](https://api.visitkorea.or.kr/#/useServiceGuide/2)과 [국문 API 설명](https://www.data.go.kr/data/15101578/openapi.do), [무장애 API 설명](https://www.data.go.kr/data/15101897/openapi.do)이다. 사진 다운로드나 재배포는 이번 조사에서 수행하지 않았다.

## TourAPI: 갱신 주기 표기 차이

| 서비스 | 공공데이터포털 메타데이터 | 제공기관 서비스 명세 |
| --- | --- | --- |
| 국문 관광정보 | 실시간 | 일 1회 (`KorService2`) |
| 반려동물 동반여행 | 실시간 | 일 1회 (`KorPetTourService2`) |
| 무장애 관광정보 | 실시간 | 일 1회 (`KorWithService2`) |

포털 표기는 각각 [국문 상세](https://www.data.go.kr/data/15101578/openapi.do), [반려동물 상세](https://www.data.go.kr/data/15135102/openapi.do), [무장애 상세](https://www.data.go.kr/data/15101897/openapi.do)에서 확인했다. 일 1회 표기는 [국문 서비스 개요](https://api.visitkorea.or.kr/#/useKoreaGuide), [반려동물 서비스 개요](https://api.visitkorea.or.kr/#/useKorPetTour), [무장애 서비스 개요](https://api.visitkorea.or.kr/#/useObstacle)의 데이터 갱신주기 항목에서 확인했다.

두 표기가 같은 의미인지, 즉시 조회 가능 여부와 원천 데이터 반영 주기를 구분한 것인지 명시적인 설명은 확인하지 못했다. 따라서 사용자에게 실시간 현장 검증을 보장하는 정보로 표시하지 않는다. 각 장소의 원천 수정일, 앱에서 읽은 날짜, 동반 조건을 실제 확인한 날짜도 서로 구분해야 한다. 이 구분은 본 프로젝트의 데이터 품질 운영 제안이며 제공기관의 SLA를 뜻하지 않는다.

## VisitJeju: 별도 공개 안내 확인 결과

공식 API 안내에는 인증키가 필요하며, 활용신청을 담당자가 승인한 뒤 이메일로 키를 발급하는 절차와 과도한 트래픽 발생 시 이용 제한이 명시되어 있다. [VisitJeju API 안내](https://www.visitjeju.net/kr/visitjejuapi)

이번 공개 안내 확인으로는 무료 여부, 숫자로 된 일일 호출 한도, 초과 사용에 대한 요금·자동 과금 조건, 구체적인 승인 소요기간을 확인하지 못했다. 데이터 재사용·장기 저장 조건과 보장되는 갱신 주기도 이 문서에서는 확정하지 않는다. TourAPI의 무료·한도를 VisitJeju에 적용할 수 없다.

공식 안내에서 연결된 [VisitJeju API 가이드 PDF](https://api.visitjeju.net/file/bbsattachment/filepath/202606/15/2f62f5a7-9d71-4d0c-a43c-54321cd4b06b.pdf)는 추가 검토용 출처다. 위의 확인된 접근 절차는 공식 웹 안내를 근거로 했으며, PDF에 무료 또는 무제한이라는 조건이 있을 것으로 추정하지 않았다.

## 실행 전 남은 확인 사항

1. **TourAPI 저장 허용 범위:** 캐싱 금지가 정기 수집·정규화·파일/DB 보관에 어떻게 적용되는지 제공기관의 명시적인 답변이 필요하다. 동기화 목록 기능의 존재만으로 이 제한이 면제되지는 않는다.
2. **운영계정 한도:** 승인될 일일 트래픽, 서비스별 또는 키별 합산 범위, 리셋 시간대, 요청 실패·재시도 집계 방식은 미확인이다. 일 1,000건 안내를 전체 콘텐츠 개수로 해석하지 않는다.
3. **실제 운영 자격:** 개발계정을 실제 운영용으로 계속 사용해도 된다고 가정하지 않는다. 공식 절차상 운영계정 신청이 별도다.
4. **VisitJeju 비용과 조건:** 무료 여부 및 트래픽 조건을 확인하기 전에는 실제 호출·주기 수집을 활성화하지 않는다.
5. **갱신 품질:** 일 1회와 실시간 표기의 관계, 휴·폐업과 동반 정책의 개별 반영 지연은 미확인이다.
6. **실행 비용:** 무료 데이터 API를 선택하더라도 외부 서버·DB·스토리지·스케줄러의 과금 승인은 별도다. 자동 유료 전환·초과 과금·유료 대체 공급자 사용을 허용하지 않았다.

공개 안내에 기재된 TourAPI 기술 문의처는 `tourapi@knto.or.kr`, `070-4287-3219`이다. 이번 작업에서는 문의를 전송하거나 전화를 걸지 않았다. [제공기관 서비스 개요](https://api.visitkorea.or.kr/#/useKoreaGuide)
