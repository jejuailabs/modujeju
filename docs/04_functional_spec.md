# 04. 기능 명세

우선순위: **P0** 베타 필수, **P1** 베타 직후, **P2** 추후 검토

## F1. 동행 선택 (P0)

- 사용자는 아이, 반려견, 어르신을 하나 이상 선택한다.
- 다시 누르면 해제된다.
- 아무것도 선택하지 않으면 '다음'을 비활성화하고 안내 문구를 보여준다.
- 선택값은 URL과 `sessionStorage`에 유지한다.

**인수 조건**
- [ ] 아이와 반려견을 함께 선택해 다음 단계로 갈 수 있다.
- [ ] 뒤로 가도 선택이 유지된다.
- [ ] 스크린리더가 선택 상태를 읽는다.

## F2. 지역과 장소 유형 선택 (P0)

- 지역: 동부, 서부, 남부, 북부 중 복수 선택
- 유형: 식당, 카페, 숙소 중 복수 선택. 기본값은 모두 선택
- 지역을 하나 이상 고르면 '맞춤 장소 보기'가 활성화된다.

권역 정의:

| 권역 | 행정구역 |
|---|---|
| 북부 | 제주시 동지역(공항 포함) |
| 동부 | 조천, 구좌, 성산, 표선, 남원 |
| 서부 | 애월, 한림, 한경 |
| 남부 | 서귀포시 동지역(중문 포함), 안덕, 대정 |

**인수 조건**
- [ ] 두 권역 이상과 일부 유형을 조합할 수 있다.
- [ ] 선택 결과가 URL에 반영되어 그대로 공유된다.

## F3. 맞춤 장소 결과 (P0)

- 판정 로직은 `docs/07`을 따른다.
- 기본 표시는 맞음, 조건부, 미확인이다. 맞지 않음은 숨긴다.
- 정렬은 판정 순서, 최근 확인일, 이름 순이다.
- 결과 칩으로 동행, 지역, 유형을 바로 뺄 수 있다.
- 추가 필터:
  - 반려견 크기: 소형, 중형, 대형. 반려견 선택 시 노출
  - 반려동물 없는 곳: 아이나 어르신을 선택하고 반려견을 선택하지 않았을 때 노출
  - 지금 영업 중
  - 포장 가능
  - 맞지 않는 곳도 보기
- 카드 표시: 대표 사진, 이름, 읍면동, 판정, 사실 태그 최대 3개, 확인일
- 맞지 않는 곳도 보기에서는 이유를 카드에 표시한다.

**인수 조건**
- [ ] 아이, 반려견, 어르신을 모두 선택하면 세 조건 판정이 합쳐진다.
- [ ] `unknown`이 맞지 않음으로 표시되지 않는다.
- [ ] 광고 필드가 존재하더라도 정렬에 영향을 주지 않는다.
- [ ] 결과가 없을 때 조건 완화 제안을 보여준다.

## F4. 장소 상세 (P0)

- 사진, 이름, 유형, 주소, 전화, 영업시간, 정기 휴일, 가격대
- 동행별 판정과 이유
- 항목별 값, 메모, 근거 유형, 확인일
- 전화 걸기, 길찾기, 저장, 공유 버튼
- 카카오맵 위치 표시
- 같은 권역의 조건 맞는 대체 장소 최대 3곳
- 오래된 정보 표시와 오류 신고

**인수 조건**
- [ ] 외부 길찾기 버튼이 카카오맵, 네이버지도, 구글 지도를 연다.
- [ ] 재확인 기한이 지난 항목은 '확인 오래됨'으로 보인다.
- [ ] 휴폐업 장소는 공개 목록에서 제외되고 직접 접속 시 상태를 안내한다.

## F5. 구글 로그인 (P0)

- 저장 기능을 쓸 때 로그인을 요구한다. 검색과 상세 조회는 로그인 없이 가능하다.
- 로그인 후 원래 화면으로 돌아오고 대기 중이던 저장을 완료한다.
- 카카오톡 등 인앱 브라우저에서는 외부 브라우저 열기를 안내한다.
- 계정 삭제 시 저장 목록을 함께 삭제한다.

**인수 조건**
- [ ] 비로그인 사용자가 하트를 누르면 로그인 안내가 뜬다.
- [ ] 로그인 후 그 장소가 저장된다.
- [ ] 인앱 브라우저에서 로그인 오류 화면을 보지 않는다.

## F6. 저장 목록 (P0)

- 장소 카드와 상세에서 저장·해제한다.
- 결과 화면의 전체 저장은 현재 필터의 표시 결과를 저장한다. 많을 경우 저장 전에 개수를 확인한다.
- 저장 목록은 지역, 유형으로 정렬한다.
- 변경된 정보가 있으면 표시한다.

## F7. 공유 (P0)

- 장소 상세와 결과를 URL로 공유한다.
- Web Share API를 우선 사용하고, 없으면 링크를 복사한다.
- OG 제목, 설명, 이미지를 제공한다.
- 공유 링크에는 개인정보를 넣지 않는다.

## F8. 지도 보기 (P0)

- 결과를 지도 마커로 본다.
- 마커 색과 모양으로 판정을 구분한다.
- 마커를 누르면 카드 미리보기를 보여준다.
- 지도 로딩에 실패해도 목록을 계속 쓸 수 있다.

## F9. 언어와 테마 (P0)

- 언어: `ko`, `en`, `zh`, `ja`
- 언어 선택은 URL에 반영하고 쿠키에 저장한다.
- 번역이 없는 자유 텍스트는 한국어 원문을 표시하고 번역 미제공을 알린다.
- 테마: 시스템 설정 따름, 라이트, 다크. 선택을 기기에 저장한다.

## F10. 오류 신고 (P0)

- 장소 상세에서 항목, 설명을 입력해 제출한다.
- 로그인 없이 쓸 수 있다.
- 개인정보를 요구하지 않으며 제한 횟수를 둔다.
- 관리자 대기열에 쌓인다. 신고만으로 공개 정보가 바뀌지 않는다.

## F11. 관리자 (P0)

- 관리자 권한 계정만 `/admin`에 접근한다.
- 장소를 만들고, 수정하고, 게시·숨김·휴업·폐업 처리한다.
- 항목별 값과 메모를 입력하고 '오늘 확인'을 한 번에 기록한다.
- 전화 확인 양식으로 통화하며 입력한다.
- 재확인 기한 대기열을 정책, 운영, 물리 묶음별로 본다.
- 오류 신고 대기열을 처리한다.
- 번역 입력과 번역 상태 관리를 제공한다.
- 사진을 올리고 저작권·동의 메모를 남긴다.
- 변경 이력을 남긴다.

**인수 조건**
- [ ] 일반 로그인 사용자는 관리자 화면과 API에 접근할 수 없다.
- [ ] 게시 조건을 채우지 못한 장소는 게시되지 않는다.
- [ ] 게시 후 사용자 화면에 반영된다.

## F12. 측정 (P0)

개인을 식별하지 않는 이벤트만 수집한다.

- 동행 조합별 검색
- 지역, 유형 선택
- 카드 열기
- 전화, 길찾기 클릭
- 저장 시도, 로그인 전환, 저장 완료
- 공유
- 언어
- 오류 신고
