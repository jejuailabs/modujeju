# 03. 시장 근거 요약

원문과 출처 링크는 `reports/제주 키즈 펫 실버 맛집앱 시장분석.md`에 있다. 이 문서는 구현 판단에 필요한 내용만 요약한다.

## 근거의 한계

- 레딧은 접근하지 못해 근거가 없다.
- 네이버 카페와 블로그를 읽지 못했다. 보호자와 부모의 실제 글이 가장 많을 가능성이 높은 곳이다.
- 82쿡은 12건만 읽었고, 아이나 반려견을 데리고 제주에서 식사하는 글은 없었다.
- 페인포인트 순위는 측정값이 아니라 판단이다.
- 경쟁사 공백은 '찾지 못했다'는 뜻이다. 앱을 직접 설치해 확인하지 않았다.
- 숙소 조건과 외국어 수요는 집중 조사하지 않았다.
- 제주 방문객 중 동반자별 비율, 복합 일행 빈도, 지불 의향은 근거가 없다.

## 동행별 근거

### 아이

| 근거 | 수치 |
|---|---|
| 도착해서 노키즈존임을 알고 못 들어간 초등 이하 양육자 | 24%(전국) |
| 출입 제한이나 불편이 걱정돼 식당 방문을 포기한 양육자 | 34.1% |
| 온라인에 노키즈존 여부를 명시하는 데 동의 | 84% |
| 제주 노키즈존 업주 중 운영 중 전환 | 47.5% |
| 일부 공간 제한 | 31.3% |

**구현 시사점:** 아동 입장은 예/아니오로 충분하지 않다. 연령 기준, 구역 제한, 외부 음식 허용 여부, 확인일이 필요하다.

### 반려견

| 근거 | 수치 |
|---|---|
| 음식점 선택 기준: 실내 이용 가능 | 62.0%(전국) |
| 음식점 선택 기준: 견종·마릿수 허용 기준 | 38.0%(전국) |
| 제주 음식점 항목 중요도: 동반 입장 여부 / 펫 메뉴 | 4.13 / 3.52 |
| 식약처 등록 동반 음식점 중 제주 | 105곳(2026-11-07 조회, 하한) |
| 다녀온 사람의 제주 동반 여행 추천 의향 | 79.0% |

**구현 시사점:** 펫 메뉴보다 입장 조건이 우선이다. 2026년 3월 제도 시행 이후 법적 등록 상태와 업소 규정을 분리해 표기한다.

### 어르신

| 근거 | 수치 |
|---|---|
| 60세 이상의 줄서기 앱 이용자 비중 | 캐치테이블 2.8%, 테이블링 1.3%(2023) |
| 65세 이상 키오스크 주문 가능 | 17.9% |
| 65세 이상 메시지 수신 가능 | 83.6% |
| 내국인 60세 이상 방문 증가 | 2019 대비 2024 상반기 +29% |

**구현 시사점:** 어르신은 직접 설치하는 사용자보다 링크 수신자일 가능성이 높다. 측정된 사실은 아니다. '실버 맛집' 배지보다 입식, 1층, 주차 거리 같은 사실이 낫다.

## 공통 근거

- 2025년 내국인 1인 식음료 지출은 약 19만 원으로 최대 지출 항목이다.
- 내국인 방문객은 2026년 5월 이후 전년 대비 감소가 이어진다. 시장 성장에 기대면 안 된다.
- 내국인 재방문율은 90.1%로 높다. 유명 맛집 추천보다 조건 확인의 가치가 클 수 있다.
- 뒷광고 의심 게시글 2만2,011건이 지적됐다. 광고 없는 사실 정보가 차별점이 될 수 있다.
- 커뮤니티 질문은 "공항 근처, 비행기 타기 전"처럼 장소, 시간, 일행이 묶여 나온다.
- 현장 식당 이용자의 59.1%가 포장을 경험했고, 영유아와 반려견 동반이 이용 제약으로 언급된다.
- 현장 식당 선택 1순위는 맛이다. 조건만 맞고 맛없는 후보를 넣으면 사용자가 떠난다.

## 경쟁 환경

| 유형 | 대표 서비스 | 강점 | 공백 |
|---|---|---|---|
| 지도 | 네이버지도, 카카오맵, 구글맵 | 사용자, 위치, 길찾기 | 제주 특화 조건값과 항목별 확인일이 확인되지 않음 |
| 키즈 | 맘맘, 애기야가자 | 숙소 수익, 아이 필드 | 반려동물·어르신 조건 없음 |
| 펫 | 반려생활, 펫트립라이프 | 무게 필터, 숙소 | 정보 노후 지적, 아이·어르신 조건 없음 |
| 공공 | 비짓제주 혼저옵서개, EASY JEJU | 현장 확인, 무장애 정보 | 접근성과 사용 빈도가 낮음 |
| 접근성 | 윌체어, 열린관광 | 층수, 경사로 항목 | 식사 조건 관점이 약함 |

**차별점 가설:** 같은 업소 안에서 세 동행의 조건과 확인일을 함께 보여주는 서비스는 찾지 못했다.

## 요구사항 연결

| 근거 | 제품 요구사항 |
|---|---|
| 도착 후 거절 | 판정과 조건 사전 표시 |
| 노키즈·펫 정책 변화 | 항목별 확인일, 재확인 대기열 |
| 상태가 예/아니오로 안 나뉨 | 조건부와 메모 |
| 다양한 일행 구성 | 복수 선택, 가장 나쁜 조건 기준 판정 |
| 광고 불신 | 광고 분리, 근거 유형 공개 |
| 위생 대립 | 구역 분리 표시, 반려동물 없는 곳 필터 |
| 어르신의 낮은 앱 이용 | 설치 없는 웹, 큰 글자, 링크 공유 |
| 현장 실패 비용 | 전화 버튼, 포장 표시, 근처 대체 장소 |
