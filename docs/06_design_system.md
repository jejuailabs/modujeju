# 06. 같이제주 디자인 시스템

작성 기준: 2026-11-07 구현. 기준 파일은 `src/app/globals.css`, `src/messages/`, `public/assets/`이다. 이 문서는 기존 시안의 감성을 실제 탐색·상세·저장·일정 화면으로 옮길 때의 공통 기준을 정의한다.

## 디자인 방향

따뜻한 크림색 바탕, 코럴색 행동 버튼, 갈색 본문, 제주 바다와 식물의 색을 사용한다. 홈에서는 여행의 기대감을 전달하고, 결과와 상세에서는 동행 조건·금액 기준·근거를 먼저 읽을 수 있게 한다. 이미지 안에 버튼이나 텍스트를 합성하지 않고 HTML로 제공한다.

아이·반려견·어르신은 복수 선택한다. 어르신을 선택했다는 이유만으로 보행 능력을 추정하지 않는다. 실제 필요한 무단차 진입·짧은 보행 등의 조건을 별도로 선택하게 한다.

## 색 토큰

CSS의 아래 변수를 공통으로 사용한다. 화면별로 비슷한 새 색을 계속 추가하지 않는다.

| 토큰 | 라이트 | 다크 | 용도 |
|---|---|---|---|
| `--bg` | `#fffaf5` | `#201e1c` | 페이지 배경 |
| `--surface` | `#ffffff` | `#2a2724` | 카드·입력·패널 |
| `--surface2` | `#fff3e9` | `#332d27` | 보조 영역 |
| `--ink` | `#342a25` | `#f7eee4` | 본문·제목 |
| `--muted` | `#81736a` | `#baaaa0` | 보조 설명 |
| `--line` | `#ebdfd6` | `#48403b` | 경계선 |
| `--accent` | `#e9684c` | `#f28c71` | 브랜드·선택·포커스 |
| `--accent-dark` | `#c64932` | `#ffb19a` | 강조 텍스트 |
| `--accent-pale` | `#ffede4` | `#482d25` | 선택 배경 |
| `--green` | `#456c51` | `#a2c4a6` | 보조 긍정 표시 |
| `--radius` | `22px` | `22px` | 기본 패널 모서리 |
| `--shadow` | `0 8px 24px #6940250a` | `0 8px 24px #0002` | 약한 깊이 |

테마는 `html[data-theme]`로 바꾼다. 첫 방문은 OS 설정을 참고하고 사용자의 선택은 브라우저에 보관한다. 이미지 자체에 다크 필터를 씌워 정보나 분위기를 왜곡하지 않는다.

일반 텍스트와 배경은 4.5:1, 큰 제목과 조작 경계는 3:1 이상의 대비를 확인한다. 브랜드 색을 그대로 흰색 글자 아래에 쓰더라도 이 기준을 별도로 확인한다. 버튼·판정 배지는 색만으로 상태를 전달하지 않는다.

## 글자·간격·크기

- 외부 폰트 다운로드 없이 시스템 글꼴 `Arial`, `Apple SD Gothic Neo`, `Malgun Gothic`, `sans-serif`를 사용한다.
- 본문과 조작 요소는 최소 **16px**, 행간은 약 **1.65**를 기본으로 한다. 확인 날짜·출처 같은 보조 정보는 최소 **14px**을 사용한다.
- 본문 제목은 약 28–40px, 패널 제목은 20–28px, 홈 히어로 제목은 화면에 따라 39–64px을 사용한다. 번역이 길어져도 글자를 과도하게 줄이지 않고 줄바꿈한다.
- 모든 버튼·링크형 조작·선택 영역은 최소 **48×48px**의 실제 클릭 영역을 확보한다. 작은 아이콘도 주변 패딩을 포함해 이 크기를 유지한다.
- 간격 스케일은 **4 / 8 / 12 / 16 / 20 / 24 / 32 / 44 / 64px**을 기본으로 한다. 화면 바깥 여백은 모바일 20px, 중간 화면 24px, 데스크톱 32px이다.
- 패널은 보통 22px 모서리와 24–28px 안쪽 여백, 버튼은 약 13px 모서리를 쓴다. 모바일 패널은 17px 모서리와 18–22px 여백을 사용한다.

위 최소 크기는 데스크톱과 모바일 모두에 적용한다. 작은 화면에 맞춘다는 이유로 중요한 제한 문구나 선택 항목을 축소하지 않는다.

## 화면 배치

| 화면 폭 | 기본 배치 |
|---|---|
| 600px 이하 | 단일 카드 열, 하단 탐색 메뉴, 20px 바깥 여백 |
| 601–800px | 카드 2열, 상세·일정은 단일 주 열 |
| 801–1050px | 넓이에 맞춘 2–3열, 상세 보조 패널 |
| 1051px 이상 | 최대 1200px 본문, 홈 최대 1280px, 카드 3열 |

지역 선택은 넓은 화면 4열, 좁은 화면 2열이다. 장소 유형은 6종이며 모바일 결과 화면에서는 가로로 이동할 수 있다. 상세 화면의 저장·공유 영역은 모바일에서 접근하기 쉬운 위치에 둔다. 고정 하단 메뉴는 `safe-area-inset-bottom`을 반영하고 마지막 콘텐츠를 가리지 않게 여백을 확보한다.

탐색 메뉴의 중심은 장소 찾기 → 저장 → 일정이다. 홈 브랜드, 소개, 개인정보, 로그인으로 돌아가는 링크를 제공한다. 언어 전환은 현재 화면의 경로를 유지한다.

## 공통 컴포넌트

| 요소 | 구현 | 기준 |
|---|---|---|
| 페이지 제목 | `PageIntro` | 제목 1개, 짧은 설명, 필요한 경우 뒤로 이동 |
| 데이터 안내 | `DemoNotice` | 가상 장소·조건이라는 점을 결과보다 먼저 표시 |
| 동행 선택 | `CompanionPicker` | 이미지+이름+선택 표시, `aria-pressed` |
| 지역 선택 | `RegionPicker` | 풍경 이미지, 텍스트 대비용 음영, 권역 이름 |
| 유형 선택 | `TypePicker` | 아이콘+이름, 복수 선택 |
| 장소 카드 | `PlaceCard` | 이름, 지역·유형, 판정, 핵심 제한, 금액 단위, 확인 상태 |
| 상세 사실 | `.fact-list` | 항목, 값, 메모, 확인 방식·날짜를 한 묶음으로 표시 |
| 주요 행동 | `.btn.primary` | 화면의 핵심 행동에 사용 |
| 보조 행동 | `.btn.secondary` | 공유·길찾기·수정 등 보조 행동 |
| 알림·오류 | `.notice`, `role="status"`/`alert` | 수행 결과와 실패 후 다음 행동을 설명 |

목록 정렬은 판정이 우선이다. 가격이나 다른 장점으로 입장 불가를 상쇄하지 않는다. 가격 단위가 다른 카페와 숙소를 단순히 같은 숫자 기준으로 비교하지 않는다.

## 판정과 데이터 상태

| 상태 | 화면 의미 | 표현 기준 |
|---|---|---|
| `fit` | 선택한 조건과 일치 | 초록 배지와 실제 이유 |
| `conditional` | 이용에 추가 조건이 있음 | 주황 배지와 야외 전용·이동장 등의 조건 |
| `unknown` | 근거가 충분하지 않음 | 중립 배지와 미확인 항목 |
| `notFit` | 선택한 필수 조건과 충돌 | 붉은 배지와 제한 이유 |

판정은 `src/lib/verdict/`의 결과를 사용한다. 화면에서 독자적인 적합 점수를 만들지 않는다. 복수 동행의 결과는 가장 제한적인 상태를 따른다.

체중의 ‘미만’과 ‘이하’, 0원과 요금 미확인, 제한 없음과 제한 미확인을 구분한다. 보행 조건은 30분 기준을 명시한다. 사실의 확인일과 공식 원본의 수정일·수집일을 서로 대신 표시하지 않는다. 확인기한이 지난 정보는 상세에서 재확인 상태를 함께 표시한다.

데모에서는 사실 출처를 가상 조건으로 표시하고 확인일을 만들지 않는다. 실제 업체나 실제 사진으로 오해할 수 있는 표현을 쓰지 않는다. 가상 장소의 길찾기와 정보 수정 전송은 비활성이다. 현재 SVG 지도는 상대 위치 개요이며 길찾기 지도가 아니다.

## 이미지 자산

- 원본: `public/assets/images/*.png`; 앱 표시용: 같은 이름의 `.webp`.
- 히어로 1종, 동행 아바타 3종, 지역 풍경 4종, 가상 장소 3종, 장식 3종, 소개 파노라마 1종을 사용한다.
- 이미지 목록과 제작 맥락은 `design/asset-manifest.json`, `design/asset-preview.html`에 있다.
- 생성한 장소 이미지는 실제 업체 정보에 연결하지 않는다. 데모 사진에는 시연용 이미지 안내를 표시한다.
- 실제 장소를 게시할 때는 사진의 권리 근거와 출처를 관리한다. 권리를 확인하지 못한 사진은 게시하지 않고 명시적인 대체 이미지를 쓴다.
- 의미 있는 사진은 설명을 제공하고, 장식이나 주변 텍스트와 중복되는 작은 이미지는 빈 `alt`를 사용한다.

## 접근성·언어·상태 확인

네 언어(`ko`, `en`, `zh`, `ja`)의 사용자 문구는 `src/messages/`에서 관리한다. 장소의 이름·주소·설명은 locale 레코드로 제공하고 조건 enum은 메시지로 번역한다. 장식용 브랜드 문구와 일반 안내 문구를 구분한다.

키보드 포커스는 최소 3px 윤곽선과 4px 간격으로 표시한다. 입력은 label 또는 접근 가능한 이름을 제공한다. 토글은 선택 상태를 읽을 수 있게 하고, 아이콘만 있는 버튼에는 이름을 붙인다. 펼침 영역은 `aria-expanded` 또는 네이티브 `details`를 사용한다.

로딩, 결과 없음, 저장 공간 사용 불가, 공유 실패, 서버 미활성, 오류 후 재시도 상태를 각각 설명한다. 빈 결과에서 지역·가격 범위를 완화하더라도 동행 필수 조건을 자동으로 해제하지 않는다. `prefers-reduced-motion`을 반영하고 움직임 없이도 상태를 알 수 있어야 한다.

완료 점검은 라이트·다크, 390px·768px·1280px, 네 언어, 키보드만 사용한 탐색을 포함한다. 이는 검수 기준이며 검수 실행 여부는 별도 작업 결과에 기록한다.
