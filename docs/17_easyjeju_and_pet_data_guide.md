# 17. 이지제주·반려견 데이터 추가 수집 가이드

작성일: 2026-11-11. 맘맘 시설 정보 반영(`docs/16` 마지막 절) 다음 단계로, 어르신·휠체어 정보와 반려견 정보를 어디서 어떻게 더 모을지 정한다.

## 공통 원칙

- 업소 기본 정보(이름, 주소, 좌표, 사진)는 **비짓제주 공식 API**를 기준으로 한다. 다른 출처는 비짓제주 `contentsid`에 붙인다.
- 다른 출처에서는 **시설 값, 짧은 인용, 원문 링크, 조사·게시일**만 가져온다. 설명문과 사진은 옮기지 않는다.
- 출처 종류는 `official`(공공기관), `listing`(민간 앱), `phone`(전화 확인)으로 구분하고, 운영진 승인일(`verifiedAt`)이 찍혀야 화면에 나온다.
- 공식·전화 확인이 민간 앱 표기보다 우선한다. 미확인은 `unknown`으로 두고 "불가"로 바꾸지 않는다.

## 1. 이지제주 (제주관광약자접근성안내센터)

### 현황 (2026-11-11 확인)

| 항목 | 내용 |
|---|---|
| 운영 | 제주특별자치도관광약자접근성안내센터, 1566-4669, 제주시 천수동로 30 2층 |
| 규모 | 음식점 약 580곳(목록 39쪽), 숙소 약 220곳(15쪽) |
| 조사 시점 | 상세 페이지에 "25년도 조사된 접근성 정보"로 표기 |
| 사이트 | `easyjeju.net/pages.php?p=tourist&folders=restaurant`(숙소는 `accommodation`), 상세는 `&no=번호` |
| robots.txt | 일반 수집기는 `/adm/`만 차단 |
| 약관 | 제10조 1항 2호: 서비스에서 얻은 정보를 복제·출판·제3자 제공 금지. 제13조: 상업적 이용 금지 |

**결론:** 약관이 복제와 제3자 제공을 금지하므로 맘맘처럼 페이지에서 바로 읽어 쓰지 않는다. **데이터 제공을 받는 경로**로 간다.

### 확보 경로 (순서대로)

1. **센터에 데이터 제공 요청:** 공공 위탁 기관이므로 공익 목적 서비스와 출처 표기를 조건으로 업소별 접근성 항목 제공을 요청한다. 받을 형태는 CSV(업소명, 주소, 항목별 값, 조사일)다.
2. **제주도에 공공데이터 제공 신청:** 센터가 직접 줄 수 없다고 하면 공공데이터포털의 "공공데이터 제공신청"이나 제주도 관광정책 부서에 개방을 요청한다. 이미 공개된 `제주특별자치도_무장애여행정보`(data.go.kr 15097103, 이용허락 제한 없음)는 관광지 중심이라 식당·숙소는 따로 요청해야 한다.
3. **받기 전까지의 운영:** 이지제주 목록은 **전화 확인 대상 후보**로만 쓴다. 업소에 직접 확인한 결과를 `phone` 근거로 기록한다.

### 항목 대응표 (데이터를 받으면 이대로 붙인다)

| 이지제주 항목 | 우리 키 | 값 |
|---|---|---|
| 단독접근가능 | `stepFree` | yes |
| 단차 하 / 중·상 | `stepFree` | conditional / no |
| 경사로 하 / 중·상 | `ramp` | yes / conditional |
| 도움필요 하·중·상 | 메모(`note`) | 수치 그대로 기록, 판정에는 쓰지 않음 |
| 장애인 화장실 | `accessibleToilet` | yes |
| 장애인 전용 주차구역 | `accessibleParking` | yes |
| 승강기, 장애인 리프트 | `elevator` | yes(리프트는 conditional) |
| 테이블 비치 | `tableSeating` | yes |
| 보장구(휠체어) 대여 | `wheelchairRental` | yes |
| 유아차 대여 | `strollerRental` | yes |
| 아기의자 / 수유실 / 기저귀 교환대 | `highChair` / `nursingRoom` / `diaperTable` | yes |
| 주차장 | `parking` | yes |
| 장애인 객실, 안내견 출입, 점자·수어 안내 | 새 키 검토 | 받은 뒤 화면 필요성 판단 |

- 출처 종류는 `official`, 조사일은 `publishedAt`, 운영진 승인일은 `verifiedAt`.
- 매칭은 맘맘과 같은 방식(이름 정규화 + 좌표 400m + 도로명)으로 비짓제주에 붙인다. 비짓제주에 없는 곳은 1차에서 제외한다.

## 2. 반려견 데이터

### 출처별 판단

| 출처 | 제주 규모 | 담긴 정보 | 이용 조건 | 판단 |
|---|---|---|---|---|
| **비짓제주 API** `alltag` | 숙소 67곳, 식당·카페 32곳(반려 태그) | 혼저옵서개, 반려동물동반입장, 반려동물동반\_숙소 등 | 키 보유, 공식 | **바로 사용.** 동반 가능 후보로 표시하되 실내·체중 조건은 `unknown` |

| **TourAPI 반려동물 동반여행** (data.go.kr 15135102) | 미확인 | 동반 유형, 크기, 유의사항 | 무료, 개발 1,000건/일. 공식 정책에 로컬 캐싱 금지 표시 | **저장 범위 서면 문의 후 결정.** 실측 사례에서 동반 유형 80%, 크기 95%가 UNKNOWN |
| 반려생활, 펫트립라이프 | 펫트립라이프 제주 378곳 | 체중·실내 필터 | 반려생활은 앱 전용, 펫트립라이프는 AI 수집기 차단 | **제휴 문의만.** 자동 수집하지 않음 |

### 전화 확인 항목 (공공 출처가 비우는 부분)

공공 출처는 "가능" 여부만 주고 조건은 거의 비어 있다. 반려견 판정에 필요한 조건은 전화로 채운다.

1. 실내 동반 / 테라스·야외만 → `petEntry` (indoor / outdoor)
2. 체중 상한과 이하·미만 여부 → `dogMaxWeight`, `dogWeightInclusive`
3. 이동장 필수 여부 → `carrierRequired`
4. 대형견 가능 → `petLargeDog`
5. 물그릇·펫 메뉴 → `petAmenity`, 마당·운동장 → `petPlayground`, 펫 객실 → `petRoom`
6. 마리 수 제한과 추가 요금 → 메모와 가격 필드

## 4. 반영 결과 (2026-11-11)

운영자 결정으로 이지제주도 페이지 표기를 직접 읽어 반영했다(약관 제10조의 복제·제3자 제공 금지 조항은 위험으로 남아 있다). 시설 값, 짧은 인용, 원문 링크만 두고 설명문과 사진은 옮기지 않았다.

- 이지제주: 음식점 579곳, 숙소 220곳을 목록에서 받고, 이름·지역 후보 277곳의 상세 주소를 비짓제주 주소·좌표와 대조해 **264곳**을 확정했다. 주소가 다른 7곳(별관, 다른 지점 등)은 뺐다. 조사 연도는 대부분 페이지에 없어 "이지제주 접근성 정보"로 표기한다.
- 식약처: 제주 105곳 중 도로명 주소가 같은 **33곳**에 실내 동반 입장(`admissions.pet = indoor`)과 `petWelcome: yes`를 넣었다. 주소만 같고 다른 가게인 6곳은 뺐다.
- 비짓제주 반려 태그: **97곳**에 `petWelcome: conditional`(실내·체중 미확인), 숙소는 `petRoom: yes`.
- 파일: `research_notes/catalog/public-source-{spots,photos,enrichment}.json`. 신규 업소 314곳. 승인 스크립트 `scripts/approve-public-sources.mjs`(2026-11-11 전체 승인).
- 새 아이콘 키: `petWelcome`(반려견 동반 표기).

## 5. 확인하지 못한 것

- 이지제주 정확한 업소 수와 비짓제주와 겹치는 비율(목록 쪽수로 추정)
- 이지제주 데이터의 공공누리 유형이나 별도 개방 여부
- TourAPI 반려동물 API의 제주 건수와 항목별 채움 비율
- 혼저옵서개 2026 전수조사 결과 공개 시점
