# 구현·검증 기록

기록 갱신일: 2026-11-08

## 구현 범위

- Next.js App Router / TypeScript / Firebase 준비 코드 / Vercel 설정.
- 4개 언어, 모바일·데스크톱, 밝은 화면·어두운 화면.
- 복수 동행의 가장 엄격한 조건을 적용하는 판정과 권역·종류·가격 필터.
- 기본 자료를 실제 비짓제주 공개 페이지의 식당·카페·숙소 60곳으로 전환. 가상 장소 20개는 `DEMO_MODE=true`를 명시한 경우에만 사용.
- 실제 장소 카드에는 식당·카페·숙소 카테고리 SVG placeholder 사용. 생성 이미지나 다른 업체 사진을 해당 실존 장소의 사진으로 표시하지 않음.
- 상세 조건·출처·확인일, 저장, 1~5일 수동 일정, 순서 변경, 일정 JSON 다운로드.
- 로그인·관리자·신고·VisitJeju 가져오기 API는 구현되어 있으나 외부 서비스 게이트는 기본 비활성.

## 실제 카탈로그 확인

실제 JSON 파일을 파싱하여 확인한 결과다. 목표 개수를 완료 결과로 대신 기록하지 않았다.

| 수집 파일 | 실제 건수 | 주소 누락 | 상세 URL·콘텐츠 ID 누락 |
|---|---:|---:|---:|
| `research_notes/catalog/restaurants.json` | 20 | 0 | 0 |
| `research_notes/catalog/cafes.json` | 20 | 0 | 0 |
| `research_notes/catalog/stays.json` | 20 | 0 | 0 |
| 합계 | 60 | 0 | 0 |

60개의 `sourceId`와 상세 URL은 서로 중복되지 않는다. 모두 HTTPS 비짓제주 상세 출처를 가진다. JSON에는 식당 55건, 카페 57건, 숙소 62건의 관측 기록이 있으며, 기록 개수는 검증된 입장 정책 개수가 아니다. 지역 분류는 주소 검수로 수정할 수 있고 권역별 동일 개수를 보장하지 않는다.

조천 소재 델문도를 동부로 정정한 뒤 실제 권역 분포는 **동부 16곳, 서부 15곳, 남부 15곳, 북부 14곳**이다. 식당·숙소는 각 권역 5곳이며, 카페는 동부 6곳·서부 5곳·남부 5곳·북부 4곳이다.

## 기본 실행과 자료 한계

- `DEMO_MODE=false`, `CLOUD_SERVICES_ENABLED=false`에서 `src/data/catalog.ts`의 공식 관측 목록을 제공한다. 클라우드 비활성은 데모 선택을 뜻하지 않는다.
- 공개 UI를 직접 열람한 정적 스냅샷이다. API 승인·키를 사용한 자동 수집이나 실시간 갱신을 수행한 결과가 아니다.
- 가격·반려견 추가요금과 확인하지 못한 동행 조건은 `null`/`unknown`으로 남긴다. 특히 숙박 광고 최저가를 현재 예약 요금으로 사용하지 않는다.
- 원문 태그·관측 문장·기본 페이지 열람일과 실제 동행 정책 확인일을 구분한다. 태그 단독으로 입장 허용이나 접근성을 확정하지 않는다.
- 미확인 좌표·소요시간은 `null`이다. 임의 좌표나 0분을 실제 정보처럼 제공하지 않는다. 좌표가 없는 장소도 주소·원문 링크로 확인한다.
- 사진 권리를 확보한 실제 업체 사진이 아니므로 장소에는 `imageKind: "placeholder"`를 명시한다. 생성 이미지는 특정 실존 업체 사진으로 재사용하지 않는다.
- 원문 번역이 없는 장소명·주소는 한국어를 유지한다. 메뉴의 4개 언어 지원과 업체 정보 번역 범위를 구분한다.

## 로컬 검증 기록

전체 9개 테스트 파일 **130개 통과**, TypeScript·ESLint·프로덕션 빌드(46개 정적 페이지 생성) 통과. 외부 Firebase·비짓제주 API 통신은 mock으로 대체했다. 공식 자료 선택, 명시적 데모 선택, cloud 실패 시 무단 대체 금지, 원문 관측과 판정 사실 분리, 미확인 좌표·소요시간, null 좌표 내보내기, 한국 날짜 경계와 캐시를 검증했다.

2026-11-08 브라우저에서 실제 자료로 확인한 결과:

- 기본 목록 60곳. 로컬 프로덕션 `/api/places`도 live 60·demo 0·각 유형 20 반환.
- `고기국수` 태그 검색: 가시아방국수·올래국수 본점 2곳. 카페·숙소 유형 선택 시 각각 20곳.
- 제주 동부 선택 시 16곳. 아이+반려견 선택 시 어린이 출입 불가 카페 1곳과 펫 불가 숙소 3곳 제외, 56곳 표시.
- 허니문하우스 어린이 입장·유아 의자, 소노캄제주 지정 객실과 12kg 이하 조건·원문 출처·수집일 표시 확인.
- 가시아방국수·허니문하우스·소노캄제주 저장, 새로고침 후 3곳 유지. 식당과 숙소를 1일차에 추가 확인.
- 지도 모드에서 미확인 좌표를 임의로 그리지 않음(핀 0개), 주소 검색 링크 제공.
- 실제 장소에는 유형 안내 SVG이며 실제 사진이 아님을 표시. 프로덕션 브라우저 오류 로그 0, 가로 넘침 없음.

`applyCatalogFacts`는 직접 검토한 원문에 한해 어린이 허용 8곳·불가 1곳, 유아 의자 1곳, 펫 불가 3곳, 지정 객실의 체중 제한 등을 반영한다. 전체 장소의 운영·접근성을 확인했다고 표시하지 않는다. 전화·현장 검증은 수행하지 않았다.

## 배포·서비스 상태

이번 변경은 로컬 코드·JSON·문서 작업이다. Vercel 배포나 Firebase 규칙 배포를 완료했다고 기록하지 않는다. 사용자가 직접 진행하는 배포와 환경변수 등록은 별도로 확인해야 한다.

`.env.local`의 비밀값은 문서·로그·공개 산출물에 기록하지 않고 Git에서 제외한다. `DEMO_MODE`와 클라우드·비짓제주 활성화 플래그는 기본 `false`다. API 키 보유나 환경변수 복사만으로 서비스 사용·과금 승인이 성립하지 않는다.

클라우드를 켜면 로컬 JSON 대신 Firestore의 게시 자료를 읽는다. 데이터 이전과 게시 검수를 먼저 준비해야 하며, 오류 시 로컬·가상 자료로 조용히 대체하지 않는다. 외부 서비스의 과금 여부가 불확실하면 공급자·범위·비용·무료 한도와 초과 조건을 확인하고 명시적인 승인을 받은 뒤 실행한다. 현재 API 자동 수집·예약 작업·자동 유료 전환을 활성화하지 않았다.

재수집, 태그 분류, 책임과 인수인계 기준은 [데이터 수집·갱신 절차](13_data_collection.md)를 따른다.
