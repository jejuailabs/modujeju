# 구현·검증 기록

검증일: 2026-11-07

## 구현 범위

- Next.js App Router / TypeScript / Firebase 준비 코드 / Vercel 설정.
- 4개 언어, 모바일·데스크톱, 밝은 화면·어두운 화면.
- 복수 동행의 가장 엄격한 조건을 적용하는 판정과 권역·종류·가격 필터.
- 가상 장소 20개, AI 이미지 원본 15개와 배포용 WebP 15개, SVG 아이콘 12개.
- 상세 조건·출처·확인일, 저장, 1~5일 수동 일정, 순서 변경, 일정 JSON 다운로드.
- 로그인·관리자·신고·VisitJeju 가져오기 API는 구현되어 있으나 외부 서비스 게이트는 기본 비활성.

## 실행 검증

- 전체 단위 테스트 90개 통과. 외부 서비스는 호출하지 않았다.
- TypeScript, ESLint 통과. 프로덕션 빌드 성공, 정적 페이지 46개 생성.
- 브라우저에서 아이·반려견·어르신 동시 선택 후 아이 3세, 반려견 8kg, 유모차·무단차 요구 설정. 결과 11개에서 동부 필터 적용 후 3개 표시.
- 3개 장소 저장, 상세 정보 확인, 저장함에서 일정 화면 이동.
- 1일차에 카페·식당, 2일차에 산책로 배치. 순서 이동 성공.
- 2026-11-22 출발일 설정 후 각 일차 날짜 계산과 새로고침 후 저장 유지 확인.
- 영문 일정 JSON을 실제로 다운로드해 날짜·순서·가상 데이터 표시 확인.
- 프로덕션 서버에서 모바일 동행 선택, 결과 필터, 지도 핀→상세 링크, 다크 모드, 일본어·중국어 전환 확인. 모바일 페이지 전체 가로 넘침 없음. 프로덕션 브라우저 오류 로그 없음.
- `/api/places`는 데모 장소 20개, 외부 서비스가 꺼진 `/api/session`, `/api/admin/places`는 503 응답. Firebase Admin 비밀키가 `.next/static` 클라이언트 산출물에 포함되지 않음.
- PNG 총 33,709,367 bytes → WebP 3,744,662 bytes, 88.9% 감소. 원본 보존 및 투명도 동일.

## 배포 상태와 남은 외부 조건

사용자가 선택한 Vercel Primary 연결의 대상 팀 접근 요청이 403으로 거절되어 팀 접근 승인을 요청했다. 현재 프로젝트 생성·환경변수 등록·Vercel 배포 완료를 확인하지 못했다. 기존 로컬 CLI의 로그인 계정과 접근 가능한 팀은 이 대상과 달라 해당 CLI로 다른 팀에 배포하지 않았다.

로컬 `.env.local`에는 제공받은 Firebase 웹 설정과 서비스 계정 3개 변수, 비활성 게이트 4개가 저장되어 있으며 Git에서 제외한다. Vercel 서버 비밀값은 올바른 팀 접근이 확인된 뒤 Production Secret으로 등록해야 한다. 값은 문서나 로그에 기록하지 않는다.

실제 VisitJeju 장소 정보는 아직 수집하지 않았다. 공식 이용 승인과 키, HTTPS 요청 계약 확인이 필요하다. Firebase와 VisitJeju 유료 호출·저장·자동 과금은 활성화하지 않았다. 앱의 기본 장소와 사진은 명시적으로 표시한 시연 데이터다.

Vercel 공식 Hobby 안내는 무료 한도 초과 시 대기/정지 방식이며 개인·비상업용 제한을 명시한다. 계정의 개인 요금 표시만으로 대상 팀의 과금 조건을 확정하지 않는다. 실제 팀 요금과 사용 목적을 확인하고, 별도 과금이 발생하거나 불확실하면 사용자의 구체적 비용 승인을 먼저 받아야 한다.
