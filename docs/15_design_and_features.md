# 디자인 및 동행·시설 아이콘

2026-11-08 업데이트.

- 크림 배경, 포리스트 그린, 테라코타 강조색과 큰 제주 풍경을 사용한다. 지역 카드는 모바일에서 가로 스크롤된다. 기존 AI 풍경은 연출 이미지로 표시한다.
- 여행 설정은 동행 → 지역 → 장소·예산의 3단계다. 동행/조건 선택과 저장·일정 기능을 유지한다.
- 아이·반려견·어르신은 각각 아이 얼굴, 강아지, 은발·안경 인물의 컬러 SVG로 구분한다. 홈 첫 화면에서 동행 선택을 독립된 패널로 강조한다. 데스크톱 홈·상세는 96px, 장소 카드는 64px, 모바일 홈·상세는 72px로 표시한다.
- 장소 카드 이름 바로 아래 세 동행 정보를 표시한다. 상세 화면은 사진보다 먼저 세 동행을 큰 첫 행으로 보여주고, 9종 시설을 아래에 분리한다. 검색도 큰 동행 필터 3개와 시설 필터 9개를 분리한다. 캐릭터 색은 동행의 종류, 별도 상태 배지는 근거의 확인 상태를 의미한다.
- 전체 UI는 공식 SIL OFL 라이선스의 Pretendard Variable v1.3.9를 로컬 파일에서 제공한다. 제목·본문·버튼·관리자 화면의 기존 폰트 지정도 통일했다.
- 유아 의자, 좌식, 입식, 1층, 유모차, 무단차, 주차, 화장실, 짧은 보행은 각각 별도 아이콘이다. 확인/조건부/미확인/불가를 색과 문구로 함께 표시한다. 상세 아이콘을 누르면 조건과 확인일·출처가 열린다.
- 시설 검색은 복수 조건 AND다. `조건부 장소 포함`을 끄면 명시적으로 확인된 조건만 남는다. 미확인은 필터를 통과하지 않는다. `아이체어`, `유아의자`, `1층`, `좌식`, `반려견` 등 정확한 별칭도 시설 검색으로 처리해 미확인 원문 태그가 검색을 우회하지 못한다.
- 현장 적합성 판정과 원문 시설 표시는 별도다. 1층을 무단차로, 펫 태그를 입장 허용으로, 좌식을 어르신 친화로 추정하지 않는다. 어르신 아이콘은 확인된 무단차 이동 정보만 의미한다.

현재 60곳 자료의 직접 검증 결과: 유아 의자 1곳(허니문하우스), 주소 말미 명시 1층 3곳, 조건부 펫 객실 2곳(서머셋·소노캄). 좌식과 무단차는 근거가 없어 미확인이다. 날짜가 지난 근거는 확인 아이콘으로 남기지 않는다.

전체 로컬 테스트 244개, TypeScript와 ESLint, 프로덕션 빌드(47개 정적 페이지) 통과. 데스크톱·모바일에서 시설 검색, 조건부 장소 제외, 상세 근거 펼치기, 저장 및 일정 추가·새로고침 유지까지 확인했다. 최종 프로덕션 화면의 브라우저 오류 로그는 없었다.

외부 API 호출·클라우드 쓰기·유료 이미지 생성·Vercel 배포는 수행하지 않았다. 반복 수집의 운영 준비 상태는 `14_recurring_ingestion.md`에 구분한다.

비짓제주 API는 원본·썸네일 URL을 제공하지만 현재 실행 키가 없어 API 수집은 연결되지 않았다. 현재 60곳은 공식 페이지 관측 자료다. 공개 사진은 아직 placeholder이며, 사진이 없다는 뜻이 아니다. 이미지 필드와 개별 사진 사용조건 조사 결과는 `../research_notes/sources/visitjeju-images-2026-11-08.md`에 기록했다.
