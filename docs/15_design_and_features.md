# 디자인 및 동행·시설 아이콘

2026-11-08 업데이트.

- 크림 배경, 포리스트 그린, 테라코타 강조색과 큰 제주 풍경을 사용한다. 지역 카드는 모바일에서 가로 스크롤된다. 기존 AI 풍경은 연출 이미지로 표시한다.
- 여행 설정은 동행 → 지역 → 장소·예산의 3단계다. 동행/조건 선택과 저장·일정 기능을 유지한다.
- 아이·반려견·어르신은 기존 생성한 투명 배경 WebP(`companion-child`, `companion-dog`, `companion-senior`)를 공통 컴포넌트에서 사용한다. 별도로 그린 인물 SVG는 제거했다. 홈 첫 화면에서 동행 선택을 독립된 패널로 강조한다. 데스크톱 홈·상세는 112px, 장소 카드는 80px이며 작은 화면에서는 카드 너비에 맞춘다.
- 장소 카드 이름 바로 아래 세 동행 정보를 표시한다. 상세 화면은 사진보다 먼저 세 동행을 큰 첫 행으로 보여주고, 9종 시설을 아래에 분리한다. 검색도 큰 동행 필터 3개와 시설 필터 9개를 분리한다. 캐릭터 색은 동행의 종류, 별도 상태 배지는 근거의 확인 상태를 의미한다.
- 전체 UI는 공식 SIL OFL 라이선스의 Pretendard Variable v1.3.9를 로컬 파일에서 제공한다. 제목·본문·버튼·관리자 화면의 기존 폰트 지정도 통일했다.
- 유아 의자, 좌식, 입식, 1층, 유모차, 무단차, 주차, 화장실, 짧은 보행은 각각 별도 아이콘이다. 확인/조건부/미확인/불가를 색과 문구로 함께 표시한다. 상세 아이콘을 누르면 조건과 확인일·출처가 열린다.
- 시설 검색은 복수 조건 AND다. `조건부 장소 포함`을 끄면 명시적으로 확인된 조건만 남는다. 미확인은 필터를 통과하지 않는다. `아이체어`, `유아의자`, `1층`, `좌식`, `반려견` 등 정확한 별칭도 시설 검색으로 처리해 미확인 원문 태그가 검색을 우회하지 못한다.
- 현장 적합성 판정과 원문 시설 표시는 별도다. 1층을 무단차로, 펫 태그를 입장 허용으로, 좌식을 어르신 친화로 추정하지 않는다. 어르신 아이콘은 확인된 무단차 이동 정보만 의미한다.

기존 식당·카페·숙소 60곳 자료의 직접 검증 결과: 유아 의자 1곳(허니문하우스), 주소 말미 명시 1층 3곳, 조건부 펫 객실 2곳(서머셋·소노캄). 추가 관광지 6곳은 같은 동행·시설 구조를 사용하되, 정책 갱신일 미확인으로 시설 판정을 `unknown`으로 보존한다. 좌식과 무단차는 근거가 없어 미확인이다. 날짜가 지난 근거는 확인 아이콘으로 남기지 않는다.

전체 로컬 테스트 276개 및 이후 추가한 좌표 관련 검증 24개, TypeScript와 ESLint, 프로덕션 빌드(51개 정적 페이지) 통과. 브라우저에서 OSM 실제 타일, 핀 선택과 상세 정보 연동, 지도 확대, 관광지 필터, 1박·2박 일정 저장과 새로고침 유지까지 확인했다. 모바일 지도 화면에 가로 넘침은 없었다. WebLLM 모델 다운로드와 실제 권역 추천 반환도 확인했고 해당 실행에서 브라우저 오류는 없었다.

유료 API 호출·클라우드 쓰기·유료 이미지 생성·Vercel 배포는 수행하지 않았다. 공개 지도 타일, Wikidata 좌표 조회와 무료 모델 파일 다운로드는 사용했다. 반복 수집의 운영 준비 상태는 `14_recurring_ingestion.md`에 구분한다.

비짓제주 API는 원본·썸네일 URL을 제공하지만 현재 실행 키가 없어 API 수집은 연결되지 않았다. 현재 66곳은 공식 페이지 관측 자료다. 공개 사진은 아직 placeholder이며, 사진이 없다는 뜻이 아니다. 이미지 필드와 개별 사진 사용조건 조사 결과는 `../research_notes/sources/visitjeju-images-2026-11-08.md`에 기록했다.


## 저장 장소 지도와 숙박 권역 추천

- 홈·검색·여행 설정은 식당/카페/숙소/관광지 네 가지 분류를 제공한다. 기존 체험·산책 자료는 관광지 분류로 탐색한다.
- /my와 /saved는 같은 브라우저 저장 데이터를 사용한다. 유형별 필터, 검색, 목록/지도 전환, 숙박일수 선택을 제공한다. 별도 클라우드 동기화는 활성화하지 않았다.
- 개략 SVG 지도를 제거하고 Leaflet 1.9.4 + OpenStreetMap 표준 타일로 교체했다. 정확한 좌표 핀과 좌표 없는 장소의 권역 묶음은 구분한다. 타일 사전 다운로드와 유료 지도 fallback은 없다. OSM 출처와 실제 경로가 아닌 직선 표시는 화면에 남긴다.
- 현재 66곳 중 비자림·천지연폭포·협재해수욕장·성산일출봉 4곳만 Wikidata CC0 좌표를 검증해 반영했다. 이 좌표는 장소 중심점이며 입구나 주차장 위치를 뜻하지 않는다. 나머지 62곳은 권역 묶음으로 표시하고 주소 검색 링크를 제공한다. 출처와 좌표 검증 기록은 `../research_notes/sources/coordinate-review-2026-11-08.md`에 남겼다.
- 저장 장소만으로 1~4박 일정을 만들고 방문권역과 숙박권역을 구분한다. 동행 부적합, 폐업, 예산 초과 등은 제외한다. 숙박은 동일권역을 우선하고 인접권역의 저장숙소도 검토한다. 숙소 연박, 날짜별 순서, 숙박권역은 새로고침과 JSON 내보내기에도 보존한다.
- AI 보강은 WebLLM + Qwen2.5-0.5B-Instruct를 사용자 버튼 이후 브라우저 worker에서 실행하는 경로다. 유료 추론 API·API 키는 사용하지 않는다. 최초 모델 다운로드와 WebGPU 메모리 필요를 안내한다. AI는 허용된 권역 순서만 반환할 수 있으며 장소/시설 사실을 만들 수 없다. 실제 실행이 성공한 경우만 AI 결과로 표시한다.

[OSM 타일 정책](https://operations.osmfoundation.org/policies/tiles/)의 출처 표시·정상 캐시·Referer·현재 화면 요청 범위를 따른다. 공개 타일 서버에는 대량 사용이나 가용성 보장이 없으며 자동 유료 전환을 사용하지 않는다. [WebLLM](https://github.com/mlc-ai/web-llm)과 [Qwen2.5-0.5B-Instruct](https://huggingface.co/Qwen/Qwen2.5-0.5B-Instruct)는 Apache-2.0 공개 프로젝트다.
