# Pretendard

Unmodified Pretendard Variable v1.3.9, by Kil Hyung-jin.

- Official project: https://github.com/orioncactus/pretendard
- Font source: https://raw.githubusercontent.com/orioncactus/pretendard/v1.3.9/packages/pretendard/dist/web/variable/woff2/PretendardVariable.woff2
- License source: https://raw.githubusercontent.com/orioncactus/pretendard/v1.3.9/LICENSE
- License: SIL Open Font License 1.1; see `Pretendard-LICENSE.txt`.
- Retrieved: 2026-11-08.

The application uses `next/font/local` to serve this Korean and Latin variable font from its own origin. Runtime font loading does not depend on a third-party font CDN. The supported weight range is 45–920, matching the official stylesheet.
